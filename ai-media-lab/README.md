# AI media lab · 四项工作流

2026-10-04 源码快照 v3。代码、数据证据、测试与已知限制分别标注；数据为固定观测，不会自动持续刷新。

## 项目

- **video-workflow**：本地视频/音频→字幕、ASR、OCR与质量关卡；含可移植SenseVoice CLI与失败对照。B站匿名浏览仅取得元数据及3条匿名可见记录，未取得完整视频/评论，不推断总体观点比例。
- **video-visuals**：4种证据与实验对比布局；保留公开授权示例帧的来源/许可说明。
- **trend-visuals**：4种布局×6平台与汇总页，共28工作页和入口。初始90条记录，其中88条计入覆盖，包含3个官方榜单来源；之后3个平台复查作为单独时间对比，不合并成新增观点票数。两项排除记录及缺失值明确保留。
- **trend-research**：历史研究说明和新版typed temporal证据。定性观点/公开角色关系不是人口统计画像；不能将样本量或平台热度当作观点支持率。
- **galgame-workflow**：《片轮少女》第一章试玩版的受限解析与短片重构工具，不是原引擎玩法录像；游戏、素材和完整剧本须自行合法获取。
- **html-video-workflow**：受限静态HTML/CSS分镜+本地中文旁白+字幕→MP4，含eSpeak、AISHELL3和Melo后端。不是任意网页/JS动画录制。当前验证器检查实际媒体，输出路径采用链接防护。

## v3 修复与验证

缺失/非法点赞数不再导致导入崩溃，也不会被当成0；统计报告保留覆盖情况，不完整时抑制点赞份额。HTML验证拒绝有旧缓存但无音轨/静音的当前MP4，路径保护拒绝链接外逃。详见 QA_SUMMARY.md 和各目录测试。

历史基准与旧版本报告保留其原始语境，不代表新一轮测量。Melo样例独立ASR回译CER9.64%只是诊断；三种声音均未经人工听感验收。DOM测试不等于完整浏览器视觉/无障碍验收。

## 复现与分发

本仓库主要分发源码、受限公开事实摘要、历史指标和测试。HTML演示媒体、游戏资产、原始视频、全量评论、模型权重、虚拟环境及凭据均不包含。四张小型视频示例JPEG是授权衍生帧，保留video-visuals/README.md中的CC BY-SA署名。

分别阅读各README；静态前端以其dist/为服务器根目录。模型与依赖需另行下载，许可按组件核查：HTML代码为GPL-3.0-or-later；FunASR模型自定义许可；Melo代码/模型MIT但训练数据完整来源未披露；游戏资产有独立非商业等条件。不存在适用于全部资产的统一宽松许可。

此代码位于独立分支，不改变原仓库script目录或主分支。
