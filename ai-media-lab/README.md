# AI media lab / 四项工作流

2026-10-04 实测源代码快照。所有数据来源、失败与未测部分在各子项目说明中区分。

- video-workflow：本地视频→音讯、帧、字幕/ASR/OCR→质量关卡；B站普通浏览器仅取得元数据及3条匿名可见记录，完整视频/评论需登录。没有总体观点比例。
- video-visuals：4种布局的证据与方法对比前端。
- trend-visuals：4种布局，每种6平台页面+汇总页，共28工作页+入口。微博科技榜与抖音榜单为直接快照；其他证据等级逐条注明。
- trend-research：跨平台定性比较和方法说明；样本量不代表全站热度或观点占比。
- galgame-workflow：《片轮少女》官方第一章试玩版的安全解析与短片重构工具；不含游戏本体、原始素材或完整剧本。按文档从官方下载并遵守非商业与署名等条件。
- html-video-workflow：受限的静态HTML/CSS幻灯片+中文合成旁白+字幕→MP4，免费离线原型；不支持任意网页JS动画，机械音未通过可懂度验证。

## 隐私与版权
这里不含凭据、浏览器Cookie、模型权重、原始视频、完整评论语料或工具原始响应。示例帧保留各自来源和许可证；Galgame资产须自行合法取得。来源中的事实主张不因上榜而得到验证。

## 复现
分别阅读子目录README。模型初次下载与依赖安装可能受网络限制；失败情况有记录，不应伪报成功。使用静态服务器可查看前端；命令行流程不需要任何私密API密钥。示例MP4在对话单独交付，不放进本代码快照。

## 状态
这是初版交付代码快照，后续改进使用同一分支增量提交，不覆盖原仓库script目录或合并主分支。
