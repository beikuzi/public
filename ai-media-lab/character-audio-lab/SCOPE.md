# Character-audio dataset workflow

## Scope

Build a reproducible workflow for 5–10 second character-audio clips, separating clean and noisy inputs and evaluating voice separation where needed. The workflow is general-purpose; any individual game or character is only an example.

This checkpoint records the plan and publication boundary. It does not claim the pipeline or a real-audio benchmark is implemented or complete.

## Incremental checkpoints

1. Framework, input contracts, and synthetic tests.
2. Clip processing, clean/noisy classification, and separation evaluation.
3. Verified results, reproducibility instructions, and source/license documentation.

Each coherent checkpoint is committed separately after its relevant checks. Synthetic-test results and real-audio results must be labeled distinctly.

## Public repository boundary

Eligible material: original code, tests, generated synthetic fixtures, technical documentation, sanitized aggregate metrics, and primary source/license URLs.

Do not publish raw game/anime/film assets, dialogue transcripts, speaker-reference recordings, model weights, credentials, private user data, or runtime files. A film's Creative Commons license alone does not establish permission to distribute a voice-cloning dataset. Record source, license, permitted use, and unresolved rights before processing external audio; redistribute only where separately authorized.

This project does not train a voice clone or impersonate a speaker.
