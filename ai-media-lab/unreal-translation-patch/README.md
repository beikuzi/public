# Unreal 文本提取与独立翻译实验

优先目标是正确提取 Unreal 本地化文本；翻译模块独立放在 `translation/`。当前不是经过游戏验证的通用汉化补丁。

## 已验证的提取范围

`extraction/` 的有界 LocRes 解码器已对两个作者公开的 MIT Unreal 示例工程中五份真实编译本地化资源进行验证：17/17 条记录与独立作者参考精确一致，包含 namespace、key、source hash、文本及重复次数。示例工程关联 UE5.3 和 UE4.27；五份实际资源均为 LocRes v3。13项测试在普通和优化Python模式通过；v0–v2仅有合成测试。

这只证明松散 `.locres` 资源提取，不证明打包游戏 PAK/IoStore 解包、屏幕文本捕获或整款游戏覆盖。没有运行游戏、DLL或第三方程序。先看 [提取快速开始](extraction/快速開始.md) 和 [验证范围](extraction/README.md)。

## 封裝檢查新增結果

`package-inspection/` 只做有界唯讀PAK索引探測：16份實際PAK中11份加密索引即停止，5份未加密v11可讀索引；主包2172筆是檔案索引項目，不是文字數。沒有解碼payload，也沒有建立完整遊戲文本提取成功的證據。12項測試及16份固定SHA-256檔案的完整中繼資料重放通過。來源、原因未知處及下一步條件見 [封裝檢查說明](package-inspection/README.md)。

## 目录

- `package-inspection/`：PAK索引探測、可重放的公開中繼資料基準與測試；不包含原始包或資產。

- `extraction/`：解码器、固定版本样本下载清单、独立比对、测试。样本及完整导出文本不随源码分发，按快速开始本地重建。
- `translation/`：独立Python翻译桥。17项离线/loopback协议测试通过；默认mock，不持久缓存译文，百度文件队列持久输出默认拒绝。
- `translation/cursor-batch/`：官方Cursor SDK接口设计的批处理适配器。19项模拟测试通过；先预检输入/输出和预算。未安装或实测SDK，不是实时游戏插件。
- `research/`：运行时和供应商协议/费用/许可边界。
- `integration/`：固定上游版本的GPL源码加固diff和配置说明。apply-check及七个修改文件的静态校验通过；未编译、未安装、未进行游戏测试。

## 安全与复现

不会将未知DLL注入游戏，不修改反作弊。真实API密钥只由用户在本机环境提供；源码及示例不含密钥。远程翻译默认关闭，明确开启后会向选定服务发送文本并可能产生费用。百度实际服务条款及缓存/再分发权限仍需核实。

源码包不含游戏资产、可执行文件、完整提取文本、真实译文或模型依赖。提取文件可能含受版权保护或敏感文本，请保留在本地。每个目录的README分别说明测试命令和限制；通过测试不代表通用游戏适配完成。
